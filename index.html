🎙️ 日文語音與朗讀設定

⚠️ 找不到日文語音，朗讀會被念成中文，所以已停用。

擇一解決：

  • Windows：設定 → 時間與語言 → 語音 → 新增語音 → 選「日本語」，裝好後重新開啟瀏覽器。
  • 改用 Edge 或 Chrome：內建線上日文語音（Nanami／Google 日本語），不用另外安裝。
  • iPhone：設定 → 輔助使用 → 朗讀內容 → 聲音 → 日文。Android：設定 → 文字轉語音 → 安裝日文語音資料。
  • 或在下方填入 OpenAI API Key 使用 AI 語音。
3. 進階：OpenAI AI 語音（選填） 選配功能
