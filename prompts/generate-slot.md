# 內容要求

1. **對話**：約 100 字以內（只算日文本文），2～3 個角色，3～6 句。
   - 場景是日常生活的一個片段，例如工作、朋友、社群媒體、家庭、店裡、學校、鄰居。
   - 口吻要完全符合場景與人物關係：同事間的丁寧語、朋友或家人的常體、對客人的敬語、年輕人的口語縮約（〜ちゃう、〜てる）等，讀起來要像真人在講話。
2. **文章**：{{LEVEL}} 程度，2～4 段，共 **300～500 字**（只算日文本文，不含讀音）。文體依類別調整：
   - 評論、深度社論：提出論點並說明理由，結尾有明確主張（である體）。
   - 報導：客觀交代事件或現象的經過與背景，結尾點出意義。
   - 隨筆：以個人經驗或觀察出發，語氣柔和（です・ます體或である體皆可）。
   - 生物、科學：說明一個現象的原理或新發現，用詞準確但不艱澀。
   - 經濟：說明一個經濟現象和它對生活的影響。
   - 文學：介紹一部日本文學作品或作家，可簡短引用公有領域作品的原文。
   - 如果上面有提供取材資料，請以它為基礎**用自己的話改寫**，不可以逐字照抄新聞或網頁；沒有取材資料時，只寫一般公認的知識，不要編造統計數字、機構名稱或新聞事件。
3. **用字與文法要多樣**：
   - 以 JLPT N3～N1 範圍內的單字，以及日常生活中真的常用的詞彙為主，避免冷僻詞。
   - 同一篇裡不要反覆使用同一個文法；也請避開上面「最近已經用過」的單字和文法。
4. **讀解題**：2 題，題型比照 JLPT 讀解（例如「內容理解」「主張理解」「指示語」「原因理由」）。
   - 題目和選項用日文，每題 4 個選項，只有 1 個正確答案，錯誤選項要有迷惑性但能從本文明確判斷是錯的。
   - answer 是正確選項的索引（0～3），正確答案的位置請隨機分布。
   - explanation 用繁體中文，引用本文的關鍵句說明理由。
5. **中文翻譯**：繁體中文（台灣用語）。對話每句的 zh 只寫翻譯，不要在前面加說話者名字；translation 段數必須和 paragraphs 相同。
6. **單字與文法整理**：對話 vocab 2～3 個；文章 vocab 3～5 個、grammar 2～3 個。

# 文字標記語法（非常重要）

日文本文（dialogue.lines[].jp 和 article.paragraphs[]）使用以下標記，**不可以使用 HTML**：

- 振假名：`{漢字|かんじ}`。每個漢字詞都要加讀音，送假名寫在括號外。
  例：`{東京|とうきょう}へ{行|い}きました`、`{見積|みつ}もり`
- 常考紅底：`[[表現|級數|類別|說明]]`，級數只能是 N1～N5，類別如「單字」「文法」「慣用」「副詞」「敬語」。
  例：`[[{先方|せんぽう}|N2|單字|先方（せんぽう）：對方、客戶方]]`
  例：`[[{準備|じゅんび}が{整|ととの}い{次第|しだい}|N2|文法|～次第：一……就立刻……]]`
- **紅底數量限制**：每句對話、每段文章最多 2 個；整份（對話＋文章）最多 7 個。只標真正值得記的考點。
- 說明裡不可以出現 `|`、`[[`、`]]`、`{`、`}`。

    "translation": ["繁中翻譯段落", "..."],
    "vocab": [

    ],
    "grammar": [
      { "pattern": "～をめぐる", "reading": "", "level": "N2", "explanation": "繁中說明接續方式與意思，附本文例句" }
